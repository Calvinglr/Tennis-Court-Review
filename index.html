The map background is blocked when this page is opened as a file, because OpenStreetMap's servers refuse requests that carry no web address. The court dots and condo outlines still show. For the full map, open a terminal in the folder holding review.html, run python -m http.server 8000, and open http://localhost:8000/review.html. The "Open in OpenStreetMap" link on each card always works.
Map: red dot = court tagged in OpenStreetMap, blue dashed = mapped condo outline, grey circle = 250 m search radius, white dot = geocoded project point
